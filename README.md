# 🔐 Password Strength Checker

A simple Python program that checks the strength of a password based on its length and the characters it contains.

## Features

- Checks password length
- Checks for uppercase letters
- Checks for numbers
- Checks for special characters
- Calculates a password score out of 4
- Classifies the password as Weak, Medium, or Strong
- Provides tips for improving weak passwords

## Technologies Used

- Python
- VS Code

## How to Run

1. Make sure Python is installed.
2. Clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python Password_checker.py
